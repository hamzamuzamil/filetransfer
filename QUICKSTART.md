# Quick Start Guide

Get P2P File Share Pro up and running in 5 minutes!

## Installation

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) - Done! 🎉

## First Transfer

### Send Files

1. **Drop files** or click to select files to share
2. **Optional**: Toggle "Password Protection" and set a password
3. Click **"Generate Share Link"**
4. **Copy the link** and share it (and password if used)
5. Wait for recipient to connect
6. Transfer starts automatically! ⚡

### Receive Files

1. **Open the shared link** in your browser
2. **Enter password** if the files are protected
3. Wait for transfer to complete
4. Click **"Download"** to save files 💾

## Key Features to Try

### 🔒 Password Protection
- Toggle the password switch before generating link
- Set a strong password (min 6 characters)
- Share the password securely with recipient

### 🔄 Resume Transfer
- Start a transfer
- Close the tab or refresh the page
- Reopen the same link
- Click "Resume Transfer" when prompted

### 💾 Large Files
- Works with files of ANY size
- Automatically optimized memory usage
- Progress saved every 10 chunks

### ⏸️ Pause/Resume
- Click "Pause" during transfer
- Click "Resume" to continue
- Perfect for managing bandwidth

## Tips for Best Results

✅ **DO**:
- Use strong passwords for sensitive files
- Keep browser tab open during transfer
- Ensure stable internet connection
- Share links securely (encrypted messaging)

❌ **DON'T**:
- Close browser before transfer completes
- Use weak passwords for important files
- Share passwords in the same channel as link
- Transfer on low battery without charging

## Troubleshooting

### Connection Issues?
- Check firewall settings
- Ensure HTTPS is enabled
- Try different network
- Check browser console for errors

### Transfer Failed?
- Click "Try Again"
- Check internet stability
- Verify sufficient disk space
- Try with smaller files first

### Resume Not Working?
- Check IndexedDB is enabled
- Clear browser cache and retry
- Verify storage quota available
